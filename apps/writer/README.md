# Zaldros Writer

Наше окно в форме Word на движке LibreOffice Writer (ADR-0020, продолжение ADR-0013).

* `zaldros_writer/engine.py` — мост к движку: живой документ через UNO, плюс `convert()` через
  `soffice --convert-to` для файловых преобразований без UNO.
* `zaldros_writer/model.py` — модель Qt; без движка документ пуст и в строке состояния написано,
  какого пакета не хватает.
* `qml/Writer.qml` — лента, страница A4, строка состояния.

Запуск: `python -m zaldros_writer render --out writer.png` (или `run`). Нужен
`libreoffice-writer-nogui` и `python3-uno`; интерпретатор — тот, под который собран `python3-uno`.

Вкладка «Главная» форматирует выбранный щелчком **целый абзац**: шрифт, размер
1–400 pt, начертание (включить/выключить), выравнивание и настоящие стили Writer.
Значения и состояния кнопок читаются обратно из UNO. Без документа команды
недоступны; неготовые вкладки помечены как недоступные. Предпросмотр пока не
воспроизводит точную раскладку страниц движка.

Общие команды подготовки: [SETUP.md](../../docs/development/SETUP.md).
Обязательный реальный UNO/Qt прогон: [BUILD.md](../../docs/office/BUILD.md).

Текст можно вводить прямо в абзацах. Enter создаёт абзац, Backspace в начале и Delete
в конце объединяют соседние абзацы; объединение через таблицу запрещено. Ctrl+S
сохраняет, Ctrl+Shift+S открывает «Сохранить как» (DOCX/ODT). При закрытии с
изменениями предлагается сохранить, отказаться от изменений или отменить закрытие.
Ошибки записи сохраняют набранный черновик и не выдают сохранение за успешное.

Пока нет выделения между абзацами и редактирования таблиц/изображений; вставка
нескольких абзацев из буфера требует следующего этапа. Предпросмотр страницы и
смешанных начертаний приблизительный; движок сохраняет нетронутые текстовые runs.
