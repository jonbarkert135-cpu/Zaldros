# Bedrock Shell (prototype)

Status: **PROTOTYPE — renders, is tested, but does not yet run as a session on a real desktop.**
It is a Qt 6 / QML implementation of the Bedrock taskbar and Start menu, run today as a normal
window (or offscreen) rather than as a Wayland layer-shell surface on KWin. That last step is
Phase 4 work and is not claimed to work.

## What is real here
- Windows 11 layout and behaviour: centred taskbar group, search pill, running-app underline that
  widens for the focused app, hover/press states, Start opening with an animated rise, click-outside
  to dismiss, right-aligned tray with time above date.
- **Live system data**: the clock and date come from the real locale-formatted system time; the
  "running" underline is computed from the *real* process table (`/proc/<pid>/comm`); the Start
  footer shows real memory pressure, and shows `—` when it cannot be measured.
- Locale-aware clock: `ru` → `23.08.2026`, `en_US` → `08/23/2026`.

## What is deliberately NOT faked
- The pinned list is placeholder data in `data/pinned.json`, not parsed `.desktop` files yet.
- Tray icons show a neutral state — no invented Wi-Fi strength or battery level.
- "Рекомендуем" is intentionally empty with an explanatory line, because no usage-history service
  exists. Inventing recent files would be a fake system state (spec PART 3 §25).
- Icons are drawn as glyph + colour. No Microsoft artwork is used or shipped (spec PART 1 §2).

## Run and render
```bash
pip install PySide6-Essentials
python -m bedrock_shell run                                    # window
QT_QPA_PLATFORM=offscreen python -m bedrock_shell render --start --out start.png
python -m pytest tests -q
```

Rendered evidence lives in `docs/evidence/` and is regenerated by the tests, so a visual regression
shows up as a failing test rather than as a surprise.
