# Zaldros OS: следующий цикл разработки

Рабочий пакет подготовлен 2026-10-26 по запросу владельца. Исходная ревизия:
`12afe1f572193fa105e0b2cd27a77b0715b4d605`.

1. [Аудит текущего состояния](AUDIT.md) — что обнаружено в коде и чем подтверждено.
2. [План и критерии готовности](PLAN.md) — 20 этапов, зависимости, приоритеты.
3. [Промпты для следующих сессий](PROMPTS.md) — общий контракт и задания P01–P20.
4. [Передача контекста](PROGRESS.md) — следующий этап, результаты и блокеры.
5. [Реестр возможностей](CAPABILITIES.md) — сценарии, код, проверки и все 69 страниц Settings.
6. [Подготовка среды](SETUP.md) — единый bootstrap для tools/shell/Office и проверка зависимостей.
7. [Ориентиры Office](../office/REFERENCE_BRIEF.md) — присланные владельцем примеры и сохранение движков.

Для новой сессии достаточно: «Прочитай docs/development/README.md и PROGRESS.md,
выполни общий контракт из PROMPTS.md и первый незавершённый этап».
Если нужен строго отдельный этап, укажи его номер. При переносе в чат без доступа к
репозиторию передай общий контракт, текст нужного промпта и актуальный PROGRESS.md вместе.

Это новый план работ, а не утверждение, что старые ADR отменены или их проверки повторены.
Спецификация в spec/, решения владельца и лицензии сохраняют силу; конфликт решается явно.
Исторические отчёты не переписываются задним числом. Текущий код и свежие доказательства
важнее устаревших количеств тестов и списков «не начато».
